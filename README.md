# もぐとも（スマホブラウザ向け試作）

幼児向けの「いっしょにごはんを食べる」キャラクターアプリです。インストール不要の静的サイトです。

## できること

- 5種類のキャラクターが目を動かして顔を追います（育成で隠しキャラ1体追加）
- ライブカメラに顔の輪郭と口元を重ねて描き、口を開けるとマーカーが黄色になります。「顔を検出 / 口が開いた / ぱくっ！」の状態をリアルタイム表示します
- カメラ右上の ⤢ ボタンでプレビューを拡大できます
- 食事動作を推定したとき、カメラ映像上に「ぱくっ！✨」と星・ハートを表示します。手動「たべたよ！」でも表示します
- カメラで顔と唇の位置を端末内推論し、**口を大きく開けてから閉じる**動きを「ひと口候補」として褒めます。手・スプーン・フォークは検出不要で、食べさせてもらう場合にも対応します
- キャラクターが自分でもパクッと食べるアニメーションをします
- 自動判定が外れたときは「たべたよ！」ボタンでいつでも褒めます
- 鳴き声（音声ファイル不要のWeb Audio合成）（🔊）と効果音（🎵）を別々に ON/OFF、自動で褒める ON/OFF
- 声は日本語読み上げではなく、短い動物風の鳴き声に変更しました。
- 褒めたときにキャラクターがぴょんっと跳ね、手をふり、ほっぺと表情が変わり、ハート・キラキラが飛び出す演出を追加
- 「いっしょに ぱくっ」ではポクッ＋もぐもぐ音、「たべたよ！」や自動判定ではキラキラした褒め音が鳴ります
- 効果音・鳴き声は端末内でWAVを生成し、iPhoneではHTML音声再生を優先します。再生が拒否された場合にWeb Audioで再試行します
- カメラ映像をサーバーに送信・保存しません

> 注意：カメラ表示の「ぱくっ！」は**口を開け閉めした動作からの推定**であり、実際に食べた／飲み込んだことを確認するものではありません。あくび、会話、笑顔でも誤検出したり、顔が隠れて見逃す可能性があります。あくまで遊びの補助です。食事を強制したり、医療目的に使わないでください。

## 育成モード（2026/10更新）

5種類のキャラクターを左右スワイプ、または ‹ › ボタンで切り替えられます。顔追跡・カメラのひと口動作推定・手動「たべたよ！」の機能はそのまま利用できます。

| キャラ | 種類 | 色・見た目 | 鳴き声 |
|---|---|---|---|
| もぐちゃん | うさぎ | ピンク・長い耳 | 高めに弾む声 |
| くまぽん | くま | ブラウン・丸い耳 | 低めのゆったりした声 |
| ねこみん | ねこ | ラベンダー・三角耳 | 滑るような声 |
| こんこん | きつね | オレンジ・尖った耳 | 軽快な声 |
| ぴよまる | ひよこ | イエロー・丸い頭 | 高く短い声 |
| ルミナ（隠し） | ひみつのこ | 紫・光るボディ | きらめくような声 |

- 「たべたよ！」または自動のひと口動作推定で、現在のキャラに **+10 XP**
- レベルは **Lv.1〜Lv.10**（Lv.10でMAX）。次のレベルへのゲージ、経験値ポップアップ、レベルアップ効果音・演出があります
- **進化は5段階**：Lv.1〜3「ちびっこ（小さく丸い幼体・たまごの殻）」→ Lv.4〜5「こども（耳・手足が成長）」→ Lv.6「わかもの（尻尾などが出現）」→ Lv.7〜9「おとな」→ Lv.10「でんせつ（王冠・光る装飾）」
- 進化の境目で特別な変身アニメーション、背景の光、紙吹雪、専用メロディーが出ます
- 各キャラの声は6体別々の音程、発声の長さ、音色、リズムを合成。幼体は高く短く、成長に合わせて少し低く長く変化します
- **最初の5体すべてがLv.10** になると隠しキャラ「ルミナ」が解放されます。ルミナもLv.10まで育てられます
- キャラごとのXP・育成状況・選択キャラに加え、鳴き声・効果音・音量・自動判定設定・達成イベントを **ブラウザの localStorage に端末内自動保存** します。「いま保存」ボタンでも保存できます
- 「育成をリセット」は確認ダイアログ付きで、全キャラの進捗・回数・隠しキャラの解放を初期化します。取り消しはできません
- キャラ一覧のアイコンをタップするとそのキャラへ直接切り替わります。「📖 ずかん」で専用一覧画面を開き、キャラを選ぶと育成画面へ戻ります
- 保存内容は異なる端末・ブラウザ間では共有しません。閲覧データ消去やプライベートモードでは失われる場合があります
- ひと口検出は動作の推定であり、実際に食べたことの確認ではありません。ゲームに時間制限、食事のノルマ、ペナルティはありません

## ゲーム演出・操作（ドパガキ仕様）

- 口の開閉でひと口候補を認識、または「たべたよ！」をタップすると、**すぐに**キャラ固有の喜びアニメーション、鳴き声、XPポップアップ、星・ハート・やわらかい全画面エフェクトが出ます
- このページを開いてからの成功回数で演出がグレードアップします：**3回 NICE! / 5回 GREAT! / 10回 SUPER FEVER! / 以後5回ごとに特別演出**。コンボに時間制限はなく、XPは常に**1回 +10**で一定です。FEVERはそのページを閉じるまで続き、リロード時にはリセットされます
- 各キャラのジャンプ・回転・スクイーズ／ストレッチ、独自の鳴き声が異なります。成長段階が高いと新しい待機アニメーションが解放され、低頻度でレアリアクションも出ます（XPの増加量は同じ）
- XPゲージを画面上側に配置。次の進化レベルが近づくと予兆が出ます。進化・Lv.10到達・5体MAXでは演出の規模が大きくなります。点滅の連発は避けています
- キャラ本体の**タップ＝なでなでリアクション**（XPは増えません）。**左右スワイプ＝キャラ切り替え**。一覧の各アイコンも直接選べます
- 右上の **⚙️** で音声・効果音・**音量0〜100%**・カメラ自動判定を変更できます。音量はiOS Safariでも効くよう、生成するWAVそのものの振幅に適用します
- 初回だけ簡単な遊び方案内を表示し、以降は自動的にスキップします。設定画面から再表示できます
- アニメーションはCSS transform主体です。reduced-motionを尊重し、端末の能力や推論の遅さに応じてパーティクルを減らします。**60fpsと100〜300msの体感応答は設計目標であり、実機性能の保証ではありません**
- 口の開閉によるゲーム判定は、食べた／飲み込んだ証明ではありません。時間ノルマ、速度ボーナス、未達成ペナルティは設けていません

## テスト

依存ライブラリのインストール不要（Node.js 20以降推奨）：

```sh
node --test tests/smoke.test.cjs
```

口の開閉（開けっぱなし・クールダウン含む）、NICE/GREAT/FEVER、固定XP、全5体Lv.10→裏キャラ解放、6体の声、切り替え、初回案内、設定と育成の再読み込み、リセット、reduced-motionをテストします。

**iPhone Safari実機で別途確認が必要**：カメラ権限、MediaPipe/WASMの読み込み、実際の口の認識精度、音声出力先と消音モード、体感遅延、フレームレート。単体テストだけでは実機動作を保証できません。

## 起動方法

カメラを利用するには HTTPS 配信が必要です（`localhost` でも可）。`index.html` の静的公開で動きます。

1. GitHubで `fooping-tech/mogutomo` の公開リポジトリを作成（`main` ブランチで開始）
2. `index.html`、`README.md`、`.nojekyll` をリポジトリのルートへアップロード（このZIPはルート直下に配置できる構成）
3. Settings → Pages → **Build and deployment** → **Source: Deploy from a branch** → `main` / `/ (root)` → Save
4. 公開された `https://fooping-tech.github.io/mogutomo/` を iPhone/Android の Safari/Chrome で開く
5. 「カメラ ON」をタップしカメラ権限を許可する

※上記URLは公開設定が反映されてから利用可能になります。

PC のローカル開発では：

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` にアクセスしてください。なお **PC上の localhost をスマホから LAN 経由で開く方法では、スマホには安全なコンテキストとして扱われず、カメラが動かないことがあります**。スマホ実機テストには HTTPS の公開を推奨します。

## 技術概要

- HTML / CSS / JavaScript の1ファイルのみ。ビルド不要
- MediaPipe Tasks Vision 0.10.22-rc.20250304 Face Landmarker（初回に jsDelivr と Google Cloud Storage からダウンロード）。手の検出モデルは使用しません
- `getUserMedia({ facingMode: 'user' })`、`AudioContext`（効果音合成）、端末内 WebAssembly / WebGL 推論
- 顔ランドマークを視線位置にマッピング。上下の内唇（13/14）の距離を口幅（61/291）で正規化し、一定時間の「閉じる → 大きく開く → 閉じる」を判定
- バッテリー節約のため推論間隔は約125ms以上

## カメラ起動に失敗したとき

- iPhoneではSafariでURLを直接開いてください。アプリ内ブラウザの制約でカメラが使えない場合があります
- 権限エラーとモデル読み込みエラーは画面内で区別して表示します。「カメラのエラー詳細」を確認してください
- モデル読み込みに失敗しても映像表示と手動の「たべたよ！」は使えます

## 既知の制約

- 手や食器を映す必要はありません。口を大きく開けて閉じる動作だけを検出するため、スプーンで食べる場合や食べさせてもらう場合も対象です
- 暗い場所、口元が隠れる、カメラから遠い、複数人が映る場合は精度が低下します。口が開いている状態からの開始、一瞬の動き、長時間の開口は判定せず、連続検出にはクールダウンがあります
- 複数人が映る場合は MediaPipe が選んだ1名の顔を追跡します
- iOSでは最初のタップでAudioContextを解除します。上部の🔉ボタンで鳴き声と効果音を試せます
- iPhone/iPadでは右上の🔉で音を確認してください。端末の音量、消音モード、Bluetooth出力先も確認してください。Safariの通常タブでの実行を推奨します
- 初回のモデル読み込みにはネット接続が必要です
- MediaPipe 自体の利用状況メトリクスについては Google のプライバシー記述も確認してください

## X・LINEなどのリンクプレビュー

公開URL: https://fooping-tech.github.io/mogutomo/

- `index.html` の先頭に Open Graph / X Card のメタ情報（`summary_large_image`）を設定しています
- `og-image.png`（1200×630 px）を GitHub Pages のルートに置き、公開URLを `og:image` / `twitter:image` に指定しています
- X はリンク先のメタ情報をキャッシュするため、変更後に古い投稿へすぐ反映されない場合があります。新しい投稿で `https://fooping-tech.github.io/mogutomo/?v=og1` を試してください
- 公開反映後もプレビューが出ない場合は、画像URLがブラウザで表示できるか確認し、少し時間をおいて再試行してください
